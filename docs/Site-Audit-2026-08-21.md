**الخلاصة: توريث كامل وصحيح للترويسة/التذييل/الطباعة، لا "ترويسة فقط" كما كان مطروحًا كاحتمال.**

### 3. تبديل اللغة — تحليل `lang.js` الكامل

منطق الملف (42 سطرًا):

```js
function apply(lang) {
  var html = document.documentElement;
  html.lang = lang;
  html.dir = lang === "ar" ? "rtl" : "ltr";
  document.body.setAttribute("data-lang", lang);
  document.querySelectorAll("[data-ar]").forEach(el => el.hidden = lang !== "ar");
  document.querySelectorAll("[data-en]").forEach(el => el.hidden = lang !== "en");
  var btn = document.getElementById("langBtn");
  if (btn) btn.textContent = lang === "ar" ? "English" : "العربية";
  try { localStorage.setItem(KEY, lang); } catch (e) {}
}
function initial() {
  try {
    var saved = localStorage.getItem(KEY);
    if (saved === "ar" || saved === "en") return saved;
  } catch (e) {}
  return "ar"; // العربية افتراضيًا دائمًا، لا اعتماد على لغة المتصفح
}
```

- **`dir` يتغيّر فعليًا** (`rtl`↔`ltr`) — مؤكَّد كودًا.
- **الخط لا "يتغيّر"** بمعنى تبديل عائلة الخط — نفس `--font-family` (IBM Plex Sans Arabic + بدائل لاتينية) يُستخدم في الحالتين؛ هذا سليم تصميميًا (خط واحد يدعم اللغتين) لا نقصًا.
- **يُحفظ الاختيار** عبر `localStorage["optisoul-lang"]`، مع `try/catch` يتسامح مع تعطيل التخزين (وضع التصفح الخاص).
- **اكتمال المحتوى الإنجليزي**: عدد أزواج `data-ar`/`data-en` متطابق تمامًا (72/72 في `index.html`، 16/16 في كل من `support.html`/`privacy.html`) — لا نص عربي "يتيم" بلا مقابل إنجليزي في المحتوى المرئي.
- **ثغرة توطين حقيقية**: 4 قيم `aria-label` عربية صرفة لا تتغيّر مطلقًا مع اللغة (`nav aria-label="التنقّل الرئيسي"` في الملفات الثلاثة، و`tablist aria-label="الوحدات"` في `index.html:127`) — مستخدم قارئ شاشة بالإنجليزية سيسمع اسم المعلم الملاحي بالعربية دائمًا. **هذا ادّعاء "منفَّذ بالكامل" غير دقيق لو صدر — التنفيذ مكتمل للنص المرئي فقط، لا لأسماء المعالم الوصولية.**

### 8. الفراغ والإيقاع — هل كله من AppSpacing؟

بحث شامل عن أي قيمة `px` خام في خصائص `margin`/`padding`/`gap`/`inset` غير مغلَّفة بـ`var(--...)`:

```
$ grep -nE "(margin|padding|gap|inset)[a-z-]*:\s*[0-9]+px" assets/style.css | grep -v "var(--"
252:  gap: 4px;
```

**نتيجة واحدة فقط** من أصل النظام كله: `assets/style.css:252`، داخل `.nav-toggle .bar-line` — الفجوة بين خطوط أيقونة الهامبرغر الثلاثة مضبوطة `4px` حرفيًا بدل `var(--s1)` (نفس القيمة رقميًا، 4px = s1). ليست مخالفة قيمة، بل مخالفة توثيق/اتساق فقط — القيمة نفسها صحيحة مصادفةً.

**الخلاصة: النظام منضبط عمليًا (رقم خام واحد من ~126 قاعدة، وهو مطابق قيميًا لأقرب رمز أصلًا).**

## د. ما يحتاج فحصًا بصريًا (لا حكم — للمالك فقط)

القائمة التالية لا يمكن إثباتها أو نفيها من الشيفرة وحدها، لغياب متصفح حي في بيئة هذا التدقيق:

1. **قصّ الحروف النازلة والتشكيل** (ج ح خ ع غ) عند `line-height:1.7`/`1.3` الجديدين — القيم منطقية حسابيًا لكن لم تُصوَّر فعليًا.
2. **سلاسة حركة الظهور التدريجي وتفاعل المرور** (`transition`/`transform`) — القيم الزمنية (`--motion-fast`/`--motion-medium`) موجودة لكن الإحساس الفعلي بالحركة يحتاج معاينة.
3. **وضوح تمييز التبويب النشط** (خلفية + حد + وزن خط) في إضاءة قوية أو لضعاف البصر — الحساب الرياضي للتباين يمرّ (11.64:1) لكن الوضوح الإدراكي شيء آخر.
4. **حجب الترويسة الثابتة عند التنقّل الداخلي** — قيمة `scroll-margin-block-start:85px` محسوبة من صندوق CSS، لم تُختبر بنقر فعلي.
5. **مظهر الأيقونات الست عند 28px فعليًا على الشاشة** — التقييم في القسم ج مبني على قراءة شيفرة SVG لا رؤية مُصيَّرة.
6. **تناسق الفراغ البصري العام** بين الأقسام (خصوصًا الفجوة الجديدة 64px قبل `#modules`/`#how`/`#faq`) — هل تبدو "كافية" فعليًا أم مفرطة/غير كافية بصريًا.
7. **عرض شريط الترويسة عند 320px بالضبط** — الحساب اليدوي (~263px من أصل 288px متاحة) يمرّ بهامش ضيق، يحتاج تأكيدًا بصريًا مباشرًا خصوصًا مع نص "العربية" (أطول من "English").
8. **جودة عرض القائمة المنسدلة للجوال وتموضعها** (`position:absolute` أسفل الترويسة) — هل تتراكب مع محتوى الصفحة أم تدفعه.

### أهم ثلاثة أشياء تستحق العمل تاليًا

1. **إصلاح عدم-ظهور المحتوى بلا JS (`.reveal`)** — لأنه الفجوة الوحيدة في هذا التدقيق التي تجعل الصفحة الرئيسية فارغة بصريًا فعليًا لفئة كاملة من الزوّار (متصفحات بلا JS، أدوات فحص آلية، بعض الزاحف)، لا مجرد نقص تجميلي.
2. **تقليص حجم ملف الشعار المصدري** — لأنه أكبر عنصر منفرد في حمولة أول تحميل (144KB من 415KB)، وإصلاحه لا يتطلب أي قرار تصميمي جديد، فقط إعادة تصدير بنفس المحتوى البصري.
3. **إتاحة القائمة المنسدلة أو رابط بديل لها بلا JS على الجوال** — لأنها المسار الملاحي الوحيد أعلى الصفحة على الجوال، وغيابها بلا JS يعزل الترويسة عن وظيفتها الأساسية رغم بقاء التذييل كمخرج احتياطي.
